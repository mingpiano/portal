## 第 2 版 · 批次四之二（日历 + 学费方式，已完成，待部署）
- **日历页签**（老师/学生/家长都有）：站内月历，点某天看当天的课；“接下来的课”每节都有 Google 日历链接和 .ics（Apple 等）下载，也可一次导出全部。学生/家长只读，老师可添加（可每周重复，最多 26 节）、改时间、取消、标记已上、删除。
- **限制**：加入 Google/Apple 日历后不会自动同步；老师改时间后，网站可发邮件通知（配置项 `mail.lessonChange`，默认 true），家长需手动更新自己的日历。
- **与记课联动**：记课时填“下次上课”会自动生成一节课；老师在日历里改它，记录里的“下次上课”同步；记下一节课后，上一节和 ±3 小时内的手动课程自动变“已上”。学生首页“下次上课” = 最近一节未来的课；该学生一节日历课都没有时，退回用记课里的旧数据。
- **学费方式**：每个学生可选“每 N 节一期”（N 默认 10，1–50）或“按月”（有起始月，每月交一次）。期数多时琴键改成进度条。
- **部署**：Schema 升到 6、API 升到 5。部署后 `/exec` 应显示 `"api":5`；第一次请求会自动升级表结构，并把未来的“下次上课”转成日历课程。
- **测试**：单元 294/294；端到端新增 8 条（日历、学费方式、手机宽度）。
- 小坑记录：新类名不要和旧周视图的 `.cal` / `.ev` 重名（已改为 `.calm` / `.evrow`）。
